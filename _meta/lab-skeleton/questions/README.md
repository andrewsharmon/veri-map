# Questions

One folder per research question. To start one from Obsidian, create a note
here: give it a short name and make its first line the question. The next
`/go` in Claude turns it into a folder. Terminal alternative:
`scripts/vm question <slug> "<question>"`.

See [INDEX.md](../INDEX.md) for the current map and the scaffold's
[CLAUDE.md](../../CLAUDE.md) for the agent protocol.
